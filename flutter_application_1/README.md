# Flutter Dialog Widget Example

# Overview

This project demonstrates how to use Dialogs in Flutter.  
Dialogs are popup windows that appear on top of the screen to show important information or request user interaction.

The application includes different types of dialogs triggered by button clicks.

# Technologies Used

- Flutter
- Dart
- Material Design widgets

# How It Works

1. User presses a button.
2. `showDialog()` function is called.
3. An `AlertDialog` appears on the screen.
4. User interacts with action buttons.
5. `Navigator.pop(context)` closes the dialog.


# Key Widgets Explained

## showDialog()
Displays a popup dialog over the current screen.

# AlertDialog
Material Design dialog layout containing title, content, and actions.

#  Navigator.pop()
Closes the dialog when user presses a button.
